# AI-рекомендации подрядчиков

Проект предназначен для подбора подрядчиков для мероприятий. Система использует данные каталога, чтобы находить варианты по запросу и объяснять, почему они подходят.

## Как устроен подбор

1. Датасет содержит сведения о подрядчиках: категорию, город, цену, доступность, форматы мероприятий, языки и описание.
2. `generate_embeddings.py` преобразует описания в числовые векторы и сохраняет их в `embeddings.json`.
3. `semantic.py` сравнивает вектор запроса пользователя с векторами описаний и возвращает оценки смыслового сходства.
4. `explanations.py` формирует объяснение на основе данных запроса и подрядчика.
5. Полная система рекомендаций должна дополнительно отфильтровать подрядчиков по обязательным условиям (например, городу, дате и бюджету), отсортировать подходящих кандидатов и показать до трёх лучших.

Смысловое сходство помогает найти похожие по смыслу описания, но само по себе не проверяет цену, город или занятость на дату. Такие ограничения должны проверяться обычным кодом.

## Файлы проекта

| Файл | Назначение |
|---|---|
| `hackathon-dataset-anonymized.jsonl` | Исходный датасет подрядчиков. Сейчас его содержимое является JSON-массивом; скрипт генерации поддерживает также JSONL. |
| `generate_embeddings.py` | Создаёт эмбеддинг для описания каждого подрядчика и записывает результат в `embeddings.json`. |
| `embeddings.json` | Словарь вида `ID подрядчика: вектор описания`. Генерируется скриптом и не хранится в Git. |
| `semantic.py` | Загружает эмбеддинги, создаёт эмбеддинг запроса и вычисляет косинусное сходство. |
| `explanations.py` | Строит объяснение соответствия из проверяемых полей и текста описания. |

## Требования

- Python 3.10 или новее
- OpenAI API key
- Пакеты `openai`, `python-dotenv`, `numpy`

Установите зависимости:

```bash
pip install openai python-dotenv numpy
```

Создайте файл `.env` в корне проекта и добавьте ключ:

```env
OPENAI_API_KEY=ваш_api_ключ
```

Не публикуйте `.env` и не добавляйте API key в исходный код.

## Создание эмбеддингов

В структуре backend из GitHub датасет должен лежать в `backend/data/`, а скрипт — в `backend/scripts/`. Генератор ищет сначала `hackathon-dataset-anonymized.jsonl`, затем `contractors.jsonl`, и сохраняет `embeddings.json` в ту же папку `data/`. Запуск из папки `backend/`:

```bash
python scripts/generate_embeddings.py
```

При локальном запуске без папок `scripts/` и `data/` скрипт использует файлы рядом с собой: `python generate_embeddings.py`.

Скрипт отправит описания в OpenAI с моделью `text-embedding-3-small` и сохранит результат в `embeddings.json`. Для этого требуется интернет-соединение и действующий API key. Повторный запуск заново обработает датасет.

## Использование семантической оценки и объяснений

```python
from semantic import get_semantic_scores
from explanations import generate_explanation

contractor = {
    "id": "HK-12345",
    "categories": ["Фотограф"],
    "event_formats": ["свадьба"],
    "price_from_kzt": 150000,
    "languages": ["русский"],
    "busy_dates": [],
    "max_hours": 8,
    "description": "Фотосъёмка камерных свадеб и семейных мероприятий.",
}

scores = get_semantic_scores(
    "Нужен фотограф для небольшой свадьбы"
)

explanation = generate_explanation(
    contractor,
    {
        "event_format": "свадьба",
        "category": "Фотограф",
        "budget": 200000,
        "date": "2026-10-15",
        "language": "русский",
        "duration": 6,
    },
)
```

`get_semantic_scores()` возвращает словарь с ID подрядчиков и оценками сходства. Более высокая оценка означает более близкое смысловое соответствие. Функция не применяет жёсткие фильтры и не выбирает TOP 3 — это задачи интеграции с рекомендательной логикой.

`generate_explanation()` возвращает текстовое объяснение на основе переданных словарей. Она не проверяет сама, прошёл ли подрядчик фильтрацию; вызывайте её для уже отобранного кандидата.
